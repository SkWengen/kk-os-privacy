KK-OS Gmail Agent

Privacy Policy

Effective date: October 3, 2026

Who this applies to

KK-OS Gmail Agent is a private tool built and used by Karim Katabi to work with his own Gmail and Google Workspace mailboxes. It is not offered to the public. The only accounts connected to it are mailboxes that Karim owns or administers.

What the tool accesses

With the account owner's consent through Google's sign-in screen, the tool can read and search messages, read and apply labels, and create drafts. It cannot send email and it cannot permanently delete email. Messages that need deleting are labelled, and the owner deletes them by hand.

Where the data goes

The tool runs on the owner's own computer. Email content travels from Google directly to that computer and is not stored on any server operated for this tool. When the owner asks an AI assistant to work on a message, the relevant content is sent to that assistant's provider (currently Anthropic) only to answer that request. Access tokens are stored on the owner's computer, encrypted with Windows Data Protection (DPAPI).

What the tool does not do

It does not sell, rent or share Google user data with anyone. It does not use Google user data for advertising. It does not use Google user data to develop, improve or train generalized AI or machine learning models.

Google API Services User Data Policy

The use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

The tool keeps no copy of mailboxes. Access can be withdrawn at any time from Google Account permissions, and doing so stops all access immediately.
